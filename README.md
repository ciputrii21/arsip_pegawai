## About Laravel

Laravel is a web application framework with expressive, elegant syntax. We believe development must be an enjoyable and creative experience to be truly fulfilling. Laravel takes the pain out of development by easing common tasks used in many web projects, such as:

- [Simple, fast routing engine](https://laravel.com/docs/routing).
- [Powerful dependency injection container](https://laravel.com/docs/container).
- Multiple back-ends for [session](https://laravel.com/docs/session) and [cache](https://laravel.com/docs/cache) storage.
- Expressive, intuitive [database ORM](https://laravel.com/docs/eloquent).
- Database agnostic [schema migrations](https://laravel.com/docs/migrations).
- [Robust background job processing](https://laravel.com/docs/queues).
- [Real-time event broadcasting](https://laravel.com/docs/broadcasting).

Laravel is accessible, powerful, and provides tools required for large, robust applications.

# 🗂️ Sistem Arsip Kepegawaian Berbasis Website

---

## 🇮🇩 Bahasa Indonesia

### 📌 Tentang Proyek
Proyek ini dikembangkan selama masa magang di **Pengadilan Negeri Manado**, tepatnya di **Sub-bagian Kepegawaian, Organisasi dan Tata Laksana**. Latar belakang proyek ini adalah kebutuhan pengelolaan dokumen kepegawaian yang sebelumnya dilakukan secara manual, sehingga menyulitkan proses pencarian dan pengelolaan arsip.

Sistem ini hadir sebagai solusi pengarsipan dokumen kepegawaian secara digital berbasis website, sehingga dokumen dapat disimpan, dikelola, dan diakses dengan lebih mudah dan terorganisir.

---

### 🎯 Tujuan
- Mendigitalkan proses pengarsipan dokumen kepegawaian
- Mempermudah pencarian dan pengelolaan berkas pegawai
- Mengurangi ketergantungan pada arsip fisik/manual

---

### 🛠️ Teknologi yang Digunakan

| Komponen | Teknologi |
|---|---|
| Backend | PHP (Laravel Framework) |
| Frontend | Blade Template (Laravel) |
| Database | MySQL (via phpMyAdmin) |
| Server (Development) | Localhost (XAMPP / Laragon) |

---

### ⚙️ Fitur Utama
- Upload dan penyimpanan dokumen kepegawaian secara digital
- Pengelolaan data arsip pegawai
- Pencarian dokumen berdasarkan kategori/nama pegawai
- Tampilan dashboard pengelolaan arsip

---

### 🏢 Implementasi
Sistem ini telah diuji coba dan dijalankan di komputer kantor **Pengadilan Negeri Manado** menggunakan server lokal (*localhost*), sehingga dapat diakses melalui jaringan internal kantor selama masa magang berlangsung.

---

### ⚠️ Keterbatasan
- Sistem berjalan secara lokal (*localhost*) dan belum di-*deploy* ke server publik
- Masih dalam tahap pengembangan sederhana sesuai kebutuhan magang
- Belum memiliki fitur autentikasi bertingkat atau manajemen hak akses yang kompleks

---

## 🇬🇧 English

### 📌 About the Project
This project was developed during an internship at **Pengadilan Negeri Manado** (Manado District Court), specifically under the **Personnel, Organization, and Administration Sub-division**. The project was motivated by the need to modernize the document management process, which was previously handled manually and made it difficult to search and organize employee records.

This system provides a web-based digital archiving solution for employee documents, enabling easier storage, management, and retrieval of records.

---

### 🎯 Objectives
- Digitize the employee document archiving process
- Simplify searching and managing employee files
- Reduce reliance on physical/manual document storage

---

### 🛠️ Tech Stack

| Component | Technology |
|---|---|
| Backend | PHP (Laravel Framework) |
| Frontend | Blade Template (Laravel) |
| Database | MySQL (via phpMyAdmin) |
| Server (Development) | Localhost (XAMPP / Laragon) |

---

### ⚙️ Key Features
- Upload and digital storage of employee documents
- Employee archive data management
- Document search by category or employee name
- Archive management dashboard

---

### 🏢 Deployment
The system was tested and run on an office computer at **Pengadilan Negeri Manado** using a local server (*localhost*), accessible via the internal office network during the internship period.

---

### ⚠️ Limitations
- The system runs locally and has not been deployed to a public server
- Developed as a simple, internship-scope application
- Does not yet include advanced role-based access control or multi-level authentication

---
